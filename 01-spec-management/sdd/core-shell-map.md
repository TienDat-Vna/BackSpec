# Core vs Shell Architectural Classification Map

## 1. CORE Modules (Full Spec Required)
- Saga Orchestration & Distributed Transactions
- Transactional Outbox Publishing
- Financial Accounting & Account Balances
- Service-to-Service Authentication & Token Exchange
- Database DDL Schema Migrations

## 2. SHELL Modules (Light Spec / CRUD)
- Read-only Status Queries
- Static Configuration / Master Data lookups
- External Notification Adapters
