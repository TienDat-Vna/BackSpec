# /speckit.help — Spec-Driven Development Overview

## Quy Trình 5 Bước Cơ Bản:
1. `/speckit.constitution`: Thiết lập Hiến pháp và chuẩn mực chất lượng.
2. `/speckit.specify`: Soạn thảo đặc tả kỹ thuật `SPEC.md`.
3. `/speckit.plan`: Thiết kế kiến trúc `PLAN.md`.
4. `/speckit.tasks`: Phân rã công việc `TASKS.md`.
5. `/speckit.implement`: Thực thi lập trình và kiểm thử >= 80%.

## Các Câu Lệnh Bổ Trợ:
- `/speckit.clarify`: Làm rõ các điểm mơ hồ logic.
- `/speckit.checklist`: Tạo danh mục kiểm định Acceptance Criteria.
- `/speckit.analyze`: Kiểm tra tính nhất quán chéo.
